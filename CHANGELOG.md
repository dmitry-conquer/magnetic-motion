# Changelog

All notable changes to this project will be documented in this file.

## 0.1.0 - 2026-07-28

### Added

- Magnetic pull that activates outside element bounds.
- Pointer parallax for individual surfaces.
- Layered parallax with signed strength multipliers.
- Per-layer scale through `data-magnetic-layer-scale`.
- Combined host and layer motion through `data-magnetic-target="both"`.
- Axis, reverse, falloff, scale, and rotation controls.
- Smooth, snappy, and elastic spring presets.
- Shared pointer listener and demand-driven animation frame loop.
- Data attributes, CSS state attributes, and CSS custom properties.
- Reduced-motion and touch-pointer safeguards.
- Full start, stop, reset, refresh, update, and destroy lifecycle.
- ESM, CommonJS, TypeScript declarations, tests, and interactive documentation.
